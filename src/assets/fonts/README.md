Outfit variable font, weights 300–700, served locally in Latin and Latin Extended subsets. Vite fingerprints these assets and rewrites the Latin preload to the same URL used by CSS.

Downloaded from Google Fonts (Outfit v15) on 2026-09-10:

- Latin: https://fonts.gstatic.com/s/outfit/v15/QGYvz_MVcBeNP4NJtEtq.woff2
- Latin Extended: https://fonts.gstatic.com/s/outfit/v15/QGYvz_MVcBeNP4NJuktqQ4E.woff2
- Upstream: https://github.com/Outfitio/Outfit-Fonts

SIL Open Font License 1.1: the redistribution license is included in `public/fonts/Outfit-OFL.txt` and shipped at `/fonts/Outfit-OFL.txt`.

`font-display: optional` keeps the system fallback for a slow first visit rather than changing text metrics after rendering. A preloaded or cached font uses Outfit immediately.
